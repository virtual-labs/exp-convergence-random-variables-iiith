Visualizing Convergence in Probability

Instructions

Theory Overview

A sequence of random variables \(X_n\) converges to \(X=0\) in probability if the probability that \(X_n\) is non-zero becomes vanishingly small as \(n\) increases. Formally, for any \(\epsilon > 0\):

\( \lim_{n \to \infty} P(|X_n - 0| > \epsilon) = 0 \)

In this experiment, this simplifies to \( \lim_{n \to \infty} P(X_n = 1) = 0 \), because the width of the rectangle (which represents this probability) shrinks to zero.

Procedure

  • Enter a block number `k` to define how far the animation should run. A larger `k` will show the trend more clearly.
  • Click "Start Animation".
  • Observe both plots simultaneously:
  • The top plot (blue) shows the individual random variable \(X_n\) as a moving, shrinking rectangle.
  • The bottom plot (green) tracks the probability \(P(X_n=1)\) against \(n\).
  • Notice how the green line trends decisively towards the zero line. This is the explicit visualization of convergence in probability.

Experiment Setting: The Moving, Shrinking Rectangles

The sequence of random variables \(X_n\) is defined such that the width of the interval where \(X_n=1\) gets smaller for larger \(n\). This width is exactly the probability \(P(X_n=1)\). The animation below demonstrates that this probability approaches zero.
